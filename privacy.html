Privacy policy

Last updated: 27 September 2026

Mail jobs is a personal application used only by its owner, with the owner's own Google account.

What it accesses

With the owner's consent it uses the Gmail API with the read-only scope (https://www.googleapis.com/auth/gmail.readonly). It searches for specific messages (for example monthly statements) and reads those messages and their attachments. It cannot send, change or delete email.

What it stores and where

Figures extracted from matching documents (for example amounts, dates and usage) are stored in a database on the owner's own home server, together with a log of which messages were processed. The access token is stored on the same server and is never shared.

Sharing

Data is not sold, shared with or transferred to anyone else, and is not used for advertising. Document text may be processed by an AI model on the owner's behalf only to read the figures from a document.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, after which the stored data can be deleted from the server.
